Help with Pack the Barn for iPhone and iPad.

Need help?

If Pack the Barn is not behaving as expected, try closing and reopening the app first. If the problem continues, please contact RS Annex and include your device model, iOS/iPadOS version and a short description of what happened.

Common questions

How do I play?

Choose one of the available animal groups and place it into free spaces in the barn. Completing a full row or column clears it and makes more room. The run ends when none of the available pieces can be placed.

Why did I get “Barn Full”?

The current set of pieces cannot fit anywhere on the board. Tap Retry to start a new run and try a different packing strategy.

My best score disappeared.

Local game data can be lost if the app is deleted, device storage is reset, or app data is removed. If cloud/game-service features are added in a later release, this page will be updated.

Does the game show adverts?

Pack the Barn may use Google AdMob to display advertising. Where legally required, a consent message may be shown before personalised advertising or related data processing is used. See the Privacy Policy for details.

How do I report a bug?

Email rsannexltd@proton.me. A screenshot or short screen recording is especially useful.
