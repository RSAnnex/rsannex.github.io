Pulse Guard Support

Need help keeping the system alive? Start here.

Controls

Use the on-screen controls to rotate the defensive guns around the processors. Aim down the circuit paths and fire before the bugs reach the processor pins. Use the data-bus pulse when you need to disrupt pressure on the other processor.

If the game is not behaving correctly

  • Close Pulse Guard completely and reopen it.
  • Restart your iPhone or iPad.
  • Check that iOS and Pulse Guard are updated to the latest available versions.
  • If the problem continues, contact RS Annex with as much detail as possible.

Contact

Email rsannexltd@proton.me.

Please include your device model, iOS version, Pulse Guard app version and a short description of the problem. If useful, attach a screenshot.
